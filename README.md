# 나의 대회 기록증 (My Race Certificate)

마라톤 · 철인3종 · 그란폰도 대회 참가 후 **기록증을 저장하고 개인 기록(PB)을 관리**하는 안드로이드 앱.

## 설치 및 업데이트 방법

1. **처음 설치**: [Releases](https://github.com/yuchoi-bb/My-Race-Certificate/releases/latest)에서 최신 APK를 폰으로 다운로드해 설치합니다.
   - 설치 시 "출처를 알 수 없는 앱" 허용을 한 번 묻습니다.
2. **이후 업데이트**: 앱을 실행하면 새 버전이 있을 때 자동으로 업데이트 안내가 뜹니다. "지금 업데이트"를 누르면 앱 안에서 다운로드 후 설치 화면으로 이어집니다.

## 개발 워크플로우

- 코드를 `main` 또는 `claude/**` 브랜치에 push하면 GitHub Actions가 자동으로 서명된 APK를 빌드하고 GitHub Releases에 `v1.0.<빌드번호>` 태그로 등록합니다.
- 앱은 실행 시 GitHub Releases의 최신 버전을 확인해 자체 업데이트합니다.
- 버전 규칙: `versionCode` = GitHub Actions 빌드 번호, `versionName` = `1.0.<빌드번호>`

## 서명 키 관련 주의

`signing/release.keystore`는 자체 업데이트(동일 서명 유지)를 위해 저장소에 포함되어 있습니다.
공개 저장소이므로 추후 GitHub Secrets로 옮기는 것을 권장합니다. **이 키를 교체하면 기존 설치 위에 업데이트가 불가능**(재설치 필요)하니 삭제하지 마세요.
